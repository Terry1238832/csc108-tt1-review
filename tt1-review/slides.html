交互终端自动显示的是字符串的 repr（表示形式）；外层引号提示“这是字符串”，不是字符串内容。print 显示内容。
这里的 terminal 指 Python 的交互提示符 >>>，不是系统 shell。强调输入时用单引号或双引号，得到的字符串值相同；直接求值时显示 repr，print 显示内容。

双引号字符串里可直接写单引号；单引号字符串里要写单引号，用反斜杠 \' 转义，或改用双引号包住。
repr 会选合适的外层引号："It's OK" 在交互终端显示双引号。所以“终端永远显示单引号”不成立。
如果字符串内容含单引号，Python 的 repr 常用双引号包住。反斜杠是代码里的转义，不是输出字符。示例的打印结果均以实际 Python 运行核对。

下标 index

蓝色是从左数（从 0 开始），橙色是从右数（从 -1 开始）。

长度为 n：正下标 0 … n-1，负下标 -1 … -n。
s[0] 是第一个，s[-1] 是最后一个，s[n-1] 也是最后一个。
下标越界会 IndexError："abc"[3]。slicing 越界不会报错。

切片先看“位置”，再看字符下标

s = 'ABCDE'：蓝色数字是字符下标；下方 0…5 是字符之间的切割位置。

① s[2:4] 从位置 2 开始，也就是 C 前面。

② 到位置 4 停，在 E 前面切开。

③ 先取下标 2 的 C。

④ 再取下标 3 的 D；下标 4 的 E 不取。结果 'CD'。

顺序点四次：起点位置、终点位置、C、D。正向连续切片可以想成在字符之间下刀；下标 2 对应 C，而切割位置 2 在 C 前面。终点 4 是边界，不是最后一个被取的字符。

终点很大：切到末尾，仍不取不存在的字符

s = 'ABCDE'，len(s) = 5；合法字符下标只有 0…4。

起点：2 取 C（下标 2） 取 D（下标 3） 取 E（下标 4） 到达长度 5：停止
s[2:10] → 'CDE'。10 是终点上限，超出长度也不会报错；切片不会生成下标 5…9 的字符。
对照：单个下标 s[10] 会报 IndexError。
先让学生预测。点亮 C、D、E 后说明 5 已经到字符串末尾，10 不是要访问的字符下标。对比单下标越界会报错。

起点终点可以一正一负。先把负数换成格子位置（-8 就是 8 号格的空格），再看范围。

第三个数 step：每次跳几格

x = "0123456789"

x[::2] → '02468'：从 0 开始，每次 +2

x[1::2] → '13579'：从 1 开始，每次 +2

s[start:stop:step]：先确定范围和方向；从 start 开始，每次加 step，到达或越过 stop 时停止。stop 不取。

先截取范围，再从起点每次前进 3 格

s = 'ABCDEFGHIJK'，计算 s[3:10:3]

① 原字符串 · 上方数字是原下标
② 取出 s[3:10]：DEFGHIJ（K 在下标 10，不包含）
当前取到的字符等待取值
按 → 或空格继续；按 ← 回看
正步长的教学分解：先看 s[3:10] 的范围，再按相对起点的距离取值；这不是 Python 必须先创建中间字符串的实现说明。取出的范围必须是 DEFGHIJ，不含 K。先取 D，再从 D 走 E（1）、F（2）、G（3，取），接着 H（1）、I（2）、J（3，取）。原下标依次为 3、6、9，结果 DGJ。每次前进三格就是跨过中间两个字符，不是跳过三个再取。反向切片先确定方向，不能直接套用 s[start:stop] 的正向截取。

step 是负数：从右往左走

x = "0123456789"

x[::-2] → '97531'：省略 start 时从最后一个开始，每次 -2

x[-2::-2] → '86420'：从 -2（字符 8）开始往左

step 为负时，省略 start 是“最右边”，省略 stop 是“一直到最左边”。

反着切：先确定起点，再一格一格往左

s = 'ABCDE'，计算 s[4:0:-1]。负步长时，stop=0 仍然不包含。

取 E（下标 4） 取 D（下标 3） 取 C（下标 2） 取 B（下标 1） 到达 stop=0：A 不取
s[4:0:-1] → 'EDCB'。反向的规则也是“取 start，不取 stop”。
不要用正向的“两个切割位置夹一段”来猜负步长。负步长直接列候选字符下标：4、3、2、1，到 0 时停止且不取 A。

反向切片的一个陷阱：省略 stop ≠ 写 -1

s[::-1]：省略 start，从最后一个 E 出发。

接着取 D。

接着取 C。

接着取 B。

最后取 A → 'EDCBA'。

s[4:-1:-1] 却是 ''：显式 -1 指向最后一个字符 E，它是不包含的终点。省略 stop 才会一直走过 A。
这个例子专门防止把省略终点理解成显式 -1。反向省略 stop 使用的是越过最左侧的边界；显式 -1 会先解释成最后一个字符下标 4，因此 4:4:-1 为空。

Q13 · Refactoring 2 pts

def func(x, y):
    if x > 100 and y == 0:
        return True
    if x > 100 and y != 0:
        return True
    if x > 100:
        return False
    elif x < 0 and y == 10:
        return True
    return False

① y 要么 == 0 要么 != 0 → 两个 if 合起来就是 “x > 100 就 True”

② 能走到第 6 行，x > 100 一定是 False，这个分支永远到不了，删掉

③ 剩下：

x < 0 and y == 10 时 True

def func(x, y):
    return x > 100 or (x < 0 and y == 10)

④ 其余都是 False

括号可以不写（and 本来就先算），写上更清楚。我用 x ∈ [-50, 200)、y ∈ [-5, 20) 全部代进去比过，结果和原函数完全一样。

    """birth_date 的格式是 YYYY-MM-DD，不晚于 CURRENT_YEAR 年底。
