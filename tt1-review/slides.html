>>> y = 4

def index_of_the_second_sub(s: str, sub: str) -> int:
    """Return the index of the second sub in s.
    If s contains fewer than 2 subs, return -1.

    >>> index_of_the_second_sub("abcabc", "abc")
    3
    >>> index_of_the_second_sub("", "a")
    -1
    """
    return s.find(sub, s.find(sub) + len(sub))

内层 s.find(sub)：第一次出现的起点，"abcabc" 里是 0

+ len(sub)：跳过第一次，从 3 开始找

外层 find 从 3 找到 3；找不到就是 -1

Q11(a) · 写 description，填返回类型 1.5 pts

Q13 · Refactoring 2 pts

def func(x, y):
    if x > 100 and y == 0:

        return True

def func(x, y):
    return x > 100 or (x < 0 and y == 10)

def merge_name_marks(names, marks1, marks2):
    result = []
    for i in range(len(names)):
        result.append(names[i])
        result.append(marks1[i] + marks2[i])
    return result

每一轮放两个：先名字，再 marks1[i] + marks2[i]

空 list 时循环不跑，返回 []，第三个例子自动满足
